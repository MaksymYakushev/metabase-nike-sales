# Nike Store Analysis 

An end-to-end data analytics project based on Nike sales transactions in the United States.
The project focuses on data exploration, SQL analysis, KPI development, and interactive dashboarding in Metabase.

## Project Overview

This project analyzes Nike sales data covering 9,360 transactions across different U.S. regions from **January 1, 2020**, to **December 31, 2021**.

The goal is to transform raw sales data into actionable business insights by analyzing:    
- Sales performance
- Revenue and profit
- Product categories
- Regional performance
- Retailer performance
- Sales channels

The final result is an interactive Metabase dashboard designed to provide a clear overview of Nike's sales performance.
